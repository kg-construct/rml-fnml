### Document conventions {#conventions}

We assume readers have basic familiarity with RDF and RML concepts as defined in [[[RML-Core]]].

In this document, examples assume the following namespace prefix bindings unless otherwise stated:

| Prefix     | Namespace                                            | Description                        |
| :--------- | :--------------------------------------------------- | :--------------------------------- |
| `rml:`     | `http://w3id.org/rml/`                               | RML Core vocabulary                |
| `fno:`     | `https://w3id.org/function/ontology#`                | Function Ontology vocabulary       |
| `rml-fn:`  | `http://w3id.org/rml/fn/`                            | Standard RML functions namespace   |
| `grel:`    | `http://users.ugent.be/~bjdmeest/function/grel.ttl#` | Example function vocabulary (GREL) |
| `xsd:`     | `http://www.w3.org/2001/XMLSchema#`                  | XML Schema Datatypes               |
| `rdfs:`    | `http://www.w3.org/2000/01/rdf-schema#`              | RDF Schema vocabulary              |
| `dcterms:` | `http://purl.org/dc/terms/`                          | Dublin Core Metadata Terms         |
| `ex:`      | `http://example.com/`                                | Example domain resources           |
